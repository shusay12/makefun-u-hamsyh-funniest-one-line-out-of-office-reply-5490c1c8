An entry for the make.fun bounty [Funniest One-Line Out-of-Office Reply](https://make.fun/bounty/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8).

Running `main.py` (Python 3.13, standard library only, no network) writes
one original one-line out-of-office reply (89 characters) to `/output/entry.txt`:

> I'm out of the office until Monday — my laptop has already emailed HR about its workload.

A deadpan away-message opening with one sudden twist: the sender's own
laptop, left behind at the desk, has gone over its owner's head and
filed a complaint with HR about its workload. The joke lands on the
last three words, needs no signature or name to make sense, and reads
like a message a real person would switch on before going away. It runs
identically every time.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
